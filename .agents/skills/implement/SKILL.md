name: implement
description: "Implement a Task or Spec, then self-check it. Use when implementing a Task or Spec, or when asked to build work described by one."
---

Implement the work described by the Task or Spec you were given, then self-check it.

1. **Build.** Use /tdd where possible, at pre-agreed seams. Commit in small Conventional Commits.
2. **Check.** Run the continuous checks regularly on the touched files if possible, and the gate checks once at the end. Every gate check passes before the next step.
3. **Review.** Use /review-implementation on the diff, and fix the findings that fall within the work's scope.
